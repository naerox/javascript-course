# dogfight

Мультиплеєрна браузерна гра в реальному часі (тема — біплани). Навчальний проєкт курсу «Програмування мовою JavaScript».
Цей репозиторій — **Lab 01: The Event Loop Is the Game Loop** (тег `lab-01`): корабель на canvas, яким можна літати
в фіксованому кроці симуляції 60 Гц.

## Запуск

```bash
nvm use            # Node 22 (.nvmrc)
npm install
npm run dev        # http://localhost:5173
npm test           # юніт-тести sim, loop, interpolate (node:test)
npm run lint
```

Керування: `←/→` або `A/D` — поворот, `↑` або `W` — тяга, `R` — скинути, `T` — скриптований забіг на 5 с (для експерименту 3).

## Архітектура

```txt
src/
  main.js              зв'язує все; стан previous/current; запускає цикл
  loop.js              createLoop() + createAccumulator(): rAF + акумулятор із clamp
  stats.js             steps/s, frames/s, frameMs, deltaMs, jitter (ковзне вікно 1 с)
  input.js             createInput() — замикання над Set клавіш; readControls()
  experiments.js       навмисно «зламані» варіанти (?exp=block|interval|variable)
  sim/                 чиста симуляція, БЕЗ DOM/canvas — працює і в Node
    ship.js            integrate(ship, controls, dt) → новий стан
    arena.js           ARENA 1600×900 світових одиниць, wrap
    math.js            clamp, lerp, wrapAngle, angleDelta
  render/
    canvas.js          DPR, масштабування арени у вікно (letterbox)
    interpolate.js     lerpShip: інтерполяція позиції (з wrap) та кута (через ±π)
    draw.js            сітка, біплан, HUD
```

Ключові рішення:

- `integrate` **не мутує** вхід і повертає новий об'єкт — тому `previous`/`current` для інтерполяції це просто два посилання.
- Симуляція працює у _світових одиницях_, а не в пікселях: розмір вікна/DPR не впливають на фізику.
- `justPressed` — по **кроках симуляції**, а не по кадрах: кадр може виконати 0 або кілька кроків, і швидкий тап не має губитись.
- Drag — експоненційний (`v *= e^(-k·dt)`), тож його ефект не залежить від того, як нарізано час.
